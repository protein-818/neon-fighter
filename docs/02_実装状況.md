### Version 60 で足したこと（依頼_キャラ_01：ブレイズの溜め）
- 強・→強・気弾を押し続けると溜める。定数は `CHGT=30`（押してから最大まで）、`CHGA=30`（最大から自動で出るまで）、`CHGK=1.3`（最大の威力）。技データの `chg`（見る入力名）と `mx`（最大溜め版）で持つ。`MV(f)` は最大で出したとき（`f.cm`）に `mx` を返す。
- 押している間の情報は `f.in.hx`（強）と `f.in.ha`（必殺1）。キーボード・スマホのボタンは押す／離すで 1／0 にする。外からは **`NF_INPUT.set(p,{hx:1})`／`{ha:1}`** で渡せる（`set` に足した2項目。渡さなければ溜めは起きない）。`act` の呼び方と意味は変えていない。
- `step` の攻撃処理で、`chg` のある技が `at==su-1` に来たとき、押されていれば進めずに `f.cg` を数える。離すか `CHGT+CHGA` で `f.cq=1`、`f.cg>=CHGT` なら `f.cm=1`。
- CPU は `blazeAI`（ノーマル以上）。最大溜めの回数はヘルで1試合 約1.6回、ノーマルで 約0.3回。
- 見た目は `figure` の中で、溜めている手足の先にキャラ色の炎と光。最大で白く光り、輪と合図の音（`SFX.chg`）。最大溜めのヒットは輪2つと強い揺れ。戦闘中の文字は足していない。
- ブレイズ以外の数値と CPU は変えていない。乱数を固定した総当たりで、ブレイズの出ない試合の結果が Version 59 と完全に同じことを確認した。

### Version 59 で足したこと（依頼B：2人対戦）
- `VS2`（2人対戦中）。`start` で `B` を `cpu=false` で作る。`act(k,re,p)` は `p`（0=1P、1=2P）で相手を分ける。先行入力も2P側に対応。
- **入力の受け口 `window.NF_INPUT`**: `set(p,{l,r,u,d,g})`（方向とガードの 0/1。渡した項目だけ変える）と `act(p,k)`（`k` は `z x c a s d f`）。2人対戦のキーボード入力もここを通る。VS CPU でも `p=0` は使える。`p=1` は2人対戦のときだけ効く。
- キーは `vsKey` が割り当てる（1P: WASD・FGHT・CVBN、2P: 矢印・テンキー／JKL;・7890）。テンキーは `e.code` で見るので NumLock の状態に左右されない。VS CPU とトレーニングのキーは変えていない。
- キャラ選択は 1P → 2P。2P の番は `p2w()` が `ch` を一時的に `ch2` と入れ替えて既存の選択画面を使い回す（終わると戻すので、外から見える `ch` は常に 1P）。2P の色は `col2`、同キャラで 1P と同じ色は選べない。
- 2人対戦では因縁（`grudge`・`recEnd`）、難易度、CPUの型表示、観戦、PARRY の警告の輪を止める。表示は 1P／2P、決着は「1P WIN／2P WIN」。
- `NFA.matchStart` に `mode`（`vs2p`／`cpu`）を足した。`win`・`matchEnd` の `result` は 1P から見た勝ち負け（今までと同じ意味）。
- タイトルに入口（PC だけ。キーは 3）。キー案内の行を下にずらした。
- 技表のキー表示は `KP`（0=通常、1=2人対戦の1P、2=同2P）で切り替える。
- 戦闘の数値と CPU の動きは変えていない。

## 4. 検証の方法
- Node.js でスクリプトを抜き出し、Canvas をダミー化して CPU 同士の試合を高速に回す（総当たりの勝率、部位破壊の回数、NaN 検査）。
- Playwright（ヘッドレス Chromium）で PC 1000×760 とスマホ横持ち 844×390 の描画・通し試合・スクリーンショット。
- 動作を変えない整理のときは、乱数と時刻を固定して整理前後の試合結果と画面を比較する。
- 勝率は同じ設定でも±5ポイントほどぶれ、数値を少し変えただけで順位が入れ替わることがある。数値を触ったら必ず総当たりで測り直す。

## 6. 方針（ユーザー要望の要約）
- デザインはモダンなフラット、キャラはシャープなアニメ格ゲー風で配色は属性に合わせる。表情変化は入れない。
- 技は各キャラの格闘スタイルに沿わせる。フレームは人が楽しめるやや遅めの速さ。
- 部位破壊は頻発させない。
- バランスは強いキャラを弱めず弱いキャラを上げる。カグラが最強（ヘルで約70%）、他は同程度。
- 戦闘中の文字表示は出さない。コンボはつながりやすく。投げと弱攻撃は届きやすく。
