# docs

仕様書と開発の記録を置く場所。

- `01_基本仕様とルール.md`：仕様（正本）
- `02_実装状況.md`：できていること、残っている課題、コードの構成、変更の履歴（正本）

どちらも 2026-10-11 に Claude のプロジェクトから移した。以後はここが正本。Version 64 までの開発の記録（`記録_開発_V57`〜`V64`）は、書かれた時点の記録としてプロジェクトに残っている。

進行表と、開発側以外の連絡ノートはプロジェクトにある。Claude Code はプロジェクトを読めないので、開発側との連絡はここの `連絡/` で行う。

## いま入っているもの

- `連絡/`：開発側（`開発側.md`）と公開側（`公開側.md`）の連絡ノート。
- `依頼/`：開発側への依頼書を置く場所（まだ無い）。
- `引っ越し/`：開発環境の引っ越しのあいだ Claude Code が読む文書の写し（依頼書、検証の道具、引き継ぎ）。読む前に `引っ越し/README.md` の注意を見る。
