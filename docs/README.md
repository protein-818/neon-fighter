# docs

仕様書と開発の記録を置く場所。

引っ越しの段階4 で、Claude のプロジェクトにある次の文書をここへ移す。それまでの正本はプロジェクト側にある。

- `01_基本仕様とルール.md`
- `02_実装状況.md`
- 開発の記録（`記録_開発_V○○_題名.md`）

進行表と連絡ノートはプロジェクトに残す（Claude Code から読み書きできない場合だけ、`docs/連絡/` に移す）。

## いま入っているもの

- `引っ越し/`：開発環境の引っ越しのあいだ Claude Code が読む文書の写し（依頼書、検証の道具、引き継ぎ）。読む前に `引っ越し/README.md` の注意を見る。
