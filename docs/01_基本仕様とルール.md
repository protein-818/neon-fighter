## 1. モード
| モード | 内容 |
|---|---|
| 対戦 VS CPU | 2本先取（最大3ラウンド）。キャラ・カラー・CPUキャラ・ステージ・難易度を選ぶ |
| CPU同士を観戦 | 対戦設定画面から。選んだ2キャラをCPU同士で戦わせる（因縁の記録は付かない。色は両方ランダム） |
| トレーニング | ダミー相手に動きを確かめる。KOなし・部位ダメージなし |
| 2人対戦（PC専用） | 1つのキーボードで2人が同時に操作する。因縁・難易度・CPUの型・観戦はない（下の「2人対戦」） |

画面の流れ: タイトル → キャラクター選択（STEP 1/2）→ 対戦／練習の設定（STEP 2/2）→ 試合 → 結果（もう一度／キャラ変更／タイトルへ）。2人対戦は STEP 1/3（1P）→ 2/3（2P）→ 3/3（設定）。

### 2人対戦（Version 59）
- 入口はタイトル画面の「2人対戦」（キーは 3）。スマホ（タッチ操作の端末）では入口を出さない。
- 流れ: 1P キャラクター選択 → 2P キャラクター選択 → 対戦の設定（ステージだけ）→ 試合。選択は ←→ でキャラ、↑↓ でカラー、Enter で次へ。
- 同じキャラ同士のときは、2P は 1P と違う色になる（1P と同じ色は選べない）。
- ルールは VS CPU と同じ（2本先取、90秒、部位ダメージあり）。因縁の記録は付かず、入場のカードも出ない。PARRY の警告の輪は出ない。
- 表示は「1P」「2P」。決着は「1P WIN」「2P WIN」。結果の最大コンボ・PARRY・部位破壊は2人の合計（最大コンボは大きい方）。
- 画面下の必殺ボタンは2人ぶんを並べ、キーと消費ゲージだけを出す（クリックでは出せない）。ポーズ画面と設定画面にキーの一覧を出す。

| | 移動 | 弱 | 強 | 投げ | ガード | 必殺技1〜4 |
|---|---|---|---|---|---|---|
| 1P | W A S D（W ジャンプ、S しゃがみ） | F | G | H | T | C V B N |
| 2P（テンキー） | ← ↑ ↓ → | 1 | 2 | 3 | 0 | 4 5 6 + |
| 2P（テンキーなし） | ← ↑ ↓ → | J | K | L | ; | 7 8 9 0（数字の段） |

- VS CPU とトレーニングのキーは今までどおり（矢印、Z X C V、A S D F）。2人対戦のときだけ上の割り当てになる。
- ポーズは P／Esc。同時に押せるキーの数はキーボードによって違う。
- 入力の受け口は `NF_INPUT`（`02` §3）。コントローラー2台はここを通して公開側が対応する予定。

### 言語（Version 58）
- 日本語と英語を切り替えられる。タイトル画面の左上の「日本語｜English」を押すか、タイトル画面で L キー。
- 初めて開いたときは、ブラウザの言語が日本語なら日本語、それ以外は英語。選んだ言語は保存される（localStorage `nf2_lang`）。
- 訳すのは表示だけ。キャラ名の照合、保存データ（因縁・色・設定）、計測に送るキャラ名は日本語のまま変わらない。言語を変えても戦績や色は引き継がれる。
- 英語では、キャラ紹介文を単語の切れ目で折り返す。スマホの必殺ボタンは技名を2〜3行に折り返して出す。
- 道場ステージの掛け軸の「闘」は背景の絵なので、英語でもそのまま。
- 訳語の一覧は `claude/資料_開発_01_英語の訳語一覧.md`。

### トレーニング
- 上部「中央に戻す」（R）: 位置・体力・ゲージ・飛び道具を初期化。
- 下部パネル: 直前の技名、発生F・全体F、ダメージ、コンボのHIT数と合計、最大ダメージ。
- ダミー（T）: 立ち → しゃがみ → ガード → ジャンプ → CPU。ゲージ（G）: 無限⇔通常。
- 操作ガイド（H）: 10ステップ（移動／ジャンプ・しゃがみ／弱／強／派生技／空中技／ガード／投げ／必殺技／コンボ）。達成で自動進行、N で次へ。既定はOFF。
- ダミーの体力は最後の被弾から約80F後に全回復し、半分より下には減らない。

## 2. 試合ルール
- **2本先取**。1ラウンド **90秒**。時間切れは残り体力の割合が高い方の勝ち（同率はCPUの負け）。
- ラウンド開始時に `ROUND n`／`FINAL ROUND` → `FIGHT!`。KO時はスローモーション＋ズーム。無傷で勝つと PERFECT。
- 体力はキャラ基礎値×2（170〜242）。ラウンドごとに全回復。
- **ゲージ**: 最大7本（内部値28、1本=4）。攻撃を当てる・受ける・ガードで増える。ラウンド間で持ち越し。
- **部位ダメージ**（§6）: 試合の間は持ち越し、次の試合でリセット。

## 3. 操作
| 操作 | キーボード | スマホ（横持ち） |
|---|---|---|
| 移動 | ← → | 左の方向パッド（スライド可、斜め可） |
| ジャンプ／しゃがみ | ↑／↓ | パッド上／下 |
| ダッシュ／バックステップ | 前／後ろを素早く2回（14F以内） | 同左 |
| 空中ダッシュ（ゲイル） | 空中で前／後ろを素早く2回（14F以内）。1回のジャンプに1回 | 同左 |
| 弱／強／投げ | Z／X／C | 弱／強／投げ ボタン |
| ガード（押しっぱなし） | V | ガード ボタン |
| 必殺技1〜4 | A／S／D／F（画面下のボタンをクリックでも可） | 右の小ボタン4つ（技名と消費本数を表示、使えるとき金色） |
| 溜め（ブレイズ） | X・→X・A を押し続ける（2人対戦は 1P: G・C、2P: テンキー 2・4 か K・7） | 「強」ボタンと必殺ボタンの1つ目を押し続ける |
| ポーズ | P／Esc | 画面上部中央 ⏸ |
| ミュート | M | タイトル／メニュー／ポーズ右上の BGM・SE ボタン |
| メニュー | ←→ キャラ・難易度、↑↓ カラー・ステージ、C CPU、W 観戦、Enter 決定、Esc 戻る | タップ |
| 言語の切り替え | タイトル画面で L（または左上のボタン） | タイトル画面の左上のボタン |

- **派生入力**: →+弱/強 = 前派生技、↓+弱/強 = しゃがみ技、空中で弱/強 = 空中技。
- **先行入力**: 出せなかった技は9F覚えていて、出せるようになった瞬間に出る。
- **ガード**: 押している間は防御（ダメージ20%に軽減）。押してから4F以内に攻撃を受けると **PARRY**（相手が40F硬直）。下段は ↓+V のしゃがみガードでのみ防げる。上段属性の攻撃はしゃがみで避けられる。相手の攻撃が当たる直前に警告の輪が出る（緑＝今押せばPARRY）。
- **投げ（C）**: ガード不能。出した瞬間に少し踏み込み、相手との距離が 66＋技ごとの値 以内ならつかむ（実質の射程 約81〜101）。相手も投げを出していれば投げ抜け。空中・ダウン中の相手はつかめない。

## 4. 戦闘システム
- 固定60fps更新＋描画は補間。技データは 発生(su)／持続(ac)／硬直(rc)／リーチ(rg)／ダメージ(d)／のけぞり(hs)／ノックバック(kb)。読み込み時に全技のフレームを×1.15、近接リーチを+10する（§9の表は補正後の値）。
- **キャンセル**: ヒット時のみ次の技へつなげられる。弱→弱（3回まで）・→弱・強・→強・必殺／→弱→強・→強・必殺／強・→強→必殺／↓弱→↓弱・↓強・弱・強・必殺／↓強→必殺／空中弱→空中弱・空中強・必殺／空中強→必殺。
- **キャンセル加速**: キャンセルで出した技は、相手ののけぞりが切れる前に当たるよう発生が短くなり（最短3F）、離れていれば踏み込む。
- **コンボ補正**: 2技目から1技ごとに−15%（下限25%）。多段技は全段で1技と数える。
- **ダウン**: ダウン属性の技／1コンボの被ダメージがダウン耐性×2.5以上／12ヒット。多段技は最終段まで倒れない。
- **打ち上げと空中追撃**: 対空技（各キャラの↓強など）は真上に高く浮かせる。浮いた相手には3回まで追撃が当たる（ダメージ×0.7、投げ・つかみは不可）。地面に倒れた相手には当たらない。
- **アーマー**: 発生8F前〜持続中は被弾してものけぞらない（被ダメージ60%）。**当て身**: 持続中に攻撃を受けると自動で反撃。
- **ダッシュ**: 前13F（そのまま攻撃可）、後ろ9F（出始め5F無敵）。しゃがみ中・空中・両脚破壊中は不可。
- **ヒットストップ**: 通常2〜3F、ダウン技5F、PARRY 6F、当て身8F、部位破壊9F、大技（3本以上）10F＋カットイン。
- **斬撃**: 刃の技は部位への蓄積に倍率がかかる（刀・光刃・ルリの刃 ×2.6、ガロウの爪と牙 ×1.8、ジョーカーのカード斬り ×1.4、投げたカード ×1.2）。
- **打撃のゲージ削り**: ブレイズ・ボルト・タイタン・ゲイル・ルリの素手・蹴り・槌の近接技は、当てたダメージ×0.12×係数（ブレイズ1.2、タイタン1.5、ルリ1、ボルト・ゲイル0.5）だけ相手のゲージを減らす。受けた側は被弾ゲージが入らない。ガード・PARRY・アーマーには無効。
- **飛び道具**: 弾同士は相殺する。設置型は2つ。ジョーカーマインは踏むと爆発してダウン、ツララの氷柱は触れるとのけぞる（どちらも1つまで、5秒で消える）。
- 戦闘中にキャラの周りへ浮かぶ文字（BLOCK・技名・回復量など）は出さない。状態は HUD・カットイン・エフェクト・音で伝える。

### キャラ固有の仕組み
- **ブレイズ（溜め）**: 強（上段回し蹴り）・→強（正拳突き）・A（気弾）は、ボタンを押し続けると発生の直前で止まって溜める。離すと出る。押してから30Fで最大になり（白く光り、合図の音が鳴る）、最大で離すと性能が上がる。途中で離すと通常版。最大のまま押し続けると、さらに30Fで自動的に出る。溜めている間は動けず、ガードもできず、攻撃も投げも普通に受ける（溜めは消える）。気弾のゲージは押した時点の1本だけ。すぐ離せば今までと同じ動き。キャンセルから出しても溜められる（コンボは切れる）。CPU もノーマル以上で使う（PARRY を取った直後・相手がガード中に最大の正拳、相手が遠いか倒れているときに最大の気弾）。

| 技 | 通常 | 最大溜め |
|---|---|---|
| 強 上段回し蹴り | ダメージ 19.9 | ダメージ 25.9（1.3倍）＋ダウン |
| →強 正拳突き | ダメージ 21.4 | ダメージ 27.8（1.3倍）＋ガード崩し（PARRY もされない） |
| A 気弾 | ダメージ 13.3、大きさ 12、相殺の強さ 1 | 8.65×2段（合計 1.3倍）、大きさ 18、相殺の強さ 2 |

- **ボルト（ギア）**: ギアは 0〜3。自分の攻撃が当たるかガードされると +1（1つの技で1回。多段技でも +1）、投げとスウェーカウンターでも +1。のけぞると −1（相手の1つの技で1回）、PARRY されると −1、ダウン・投げ・つかみを受けると 0。240F のあいだ当てても当てられてもいないと −1。ギア1つにつき通常技（弱・→弱・強・→強・↓弱・↓強）の硬直 −1F（最短2F）、歩きとダッシュ +4%。ラウンドの開始時は 0。HUD に稲妻の印3つ、体に電光。トレーニングでも働く（「中央に戻す」で 0）。
- **タイタン（ヒート）**: ヒートは 0〜3。アーマーで相手の攻撃を耐える（相手の1つの技で1回）、投げを決める、つかみ必殺を決めると +1。被弾・ダウン・時間では減らず、ラウンドをまたいで持ち越す（試合の開始時は 0）。ヒート3でつかみ必殺（S・D・F）をつかむと強化版になり（ダメージ1.25倍。ジャーマン 38.8／パイル 50／スイング 69.4）、0 に戻る。空振りでは減らない。投げは強化されない。HUD に星の印3つ、ヒート3で金色のオーラ、上がるたびに歓声。CPU はヒート3のとき、つかみ必殺を狙う頻度が上がる。
- **カグラ（構え）**: ラウンド開始時は納刀。A（消費なし）で納刀⇔抜刀を切り替える（ヒット時のキャンセルでも可）。納刀は歩く速さ1.1倍。抜刀は腰を落とした低い正眼の構えで、通常技8種と S・D・F が剣技に変わる。投げと A は共通。HUD に現在の構えを表示。刀・ステッキ・槌は前腕で持つ扱い（§6）。
- **イヴ（段階）**: 段階1 擬態 → 段階2 解放（体力60%以下か A。攻撃×1.1、強・→強・↓強が機械技に）→ 段階3 殲滅（体力30%以下か A。攻撃×1.2・移動×1.15・被ダメージ×1.1、F が自壊コードに）。A はゲージ1本と体力5%を使う。前後ダッシュはジェット（速さ1.15倍）、空中で↑を押し続けるとホバー（燃料80F、着地で回復）。
- **ヴァンプ**: 全ての攻撃で与ダメージの15%を回復。出血中の相手からは吸血量1.5倍。ダッシュは霧になり、距離1.25倍で相手をすり抜ける（無敵 前6F・後ろ8F）。伸びる技は腕・脚が実際に伸びる。
- **ガロウ（餓狼覚醒）**: 体力が4割以下になるとカットインが入り、以後 攻撃1.3倍・移動1.2倍（被ダメージ1.1倍）。ラウンドごとに発動。常に低い姿勢（当たり判定は他キャラと同じ）。
- **ルリ**: 表示倍率0.83で最小。背中の魔法陣はゲージが溜まるほど大きく明るくなる。断頭台は相手の位置に刃が3枚落ちる。
- **ゲイル（空中ダッシュ）**: 空中で前か後ろを2回押すと、高さを保ったまま水平に滑る（前 10F・約80、後ろ 8F・約60）。1回のジャンプに1回で、着地すると戻る。二段ジャンプの前でも後でも出せる。途中と直後に空中技・空中必殺が出せる。無敵も攻撃の判定もない。のけぞり中・技の途中・両脚破壊では出ない。脚が1本壊れていると距離が約0.7倍。CPU もノーマル以上でねらって使う。
- **ゲイル・イヴ**: 二段ジャンプと空中必殺技。
- **ツララ（凍え）**: 相手ごとに凍えの値（0〜100）を持つ。ツララの技が当たると技ごとの量だけ増える（§9 の表。ガードは4分の1、PARRY・アーマー・当て身では増えない）。50 以上で段階1。100 に届くと段階2 に入り、75 を下回るまで続く。最後に氷の技を受けてから 40F たつと、1F に 0.25 ずつ減る（100 から 0 まで 約440F）。段階の数だけ、待機から出す技の発生 +1F・歩きとダッシュ −6%・ジャンプ −3%。負傷の遅れと合わせて +3F まで。キャンセルで出す技は遅れない。部位への蓄積とは別の値。ラウンドの開始と「中央に戻す」で 0。凍えている側の HUD に雪の結晶の印（段階の数）と値の棒、「凍え  技 +1F ・ 移動 −6%」の一行が出る。体に霜、段階2 で青白い光と足元の氷。
- **ツララ（滑走）**: 前ダッシュの距離が 1.2倍で、滑っている間は相手をすり抜ける。無敵はない。後ろダッシュは通常どおり。
- **ツララ（氷葬）**: F の氷葬は、相手の凍えが段階1以上のときだけ出せる（出せないときはゲージが減らず、必殺ボタンも金色にならない）。段階2 の相手にはダメージ 1.25倍。つかむと相手の凍えは 0 に戻る。

## 6. 部位ダメージ
部位は 前腕・後腕・前脚・後脚。ガードされなかった被ダメージが部位に蓄積する（下段技→脚85%、上段技→腕80%、その他は半々。1ヒットの蓄積上限は最大体力の12%、斬撃は倍率あり）。蓄積が最大体力×0.9 に達すると破壊。

| 段階 | 蓄積（破壊ラインに対して） | 腕 | 脚 |
|---|---|---|---|
| 負傷 | 45%以上 | 腕技の発生 +1F | 脚技の発生 +1F、移動 −6%、ジャンプ −3%、ダッシュ −5% |
| 重傷 | 75%以上 | 腕技の発生 +2F | 脚技の発生 +2F、移動 −12%、ジャンプ −6%、ダッシュ −10% |
| 破壊 | 100% | 下記 | 下記 |

- 発生の遅れは左右で重い方の1本ぶん（最大+2F）。移動などは左右の合計。遅れるのは待機から出した技だけで、キャンセルで出す技は遅れない。構え切替・リミッター解除・狂化は遅れない。飛び道具と投げは腕扱い。
- **破壊**: 手足が千切れて飛ぶ（斬撃で壊すと切断扱い）。
  - 腕1本につき腕技の威力 −22%。両腕で ガード・投げ不可。
  - 脚1本につき脚技の威力 −22%・移動 −22%・ジャンプ低下、歩行・着地でよろけ。両脚で立てなくなり、這って移動（ジャンプ・脚技・上昇技不可）。
  - **壊れた部位を使う技は当たらない**。腕技＝前腕、ストレート系＝後腕、左右交互の連打は段ごとに交互、脚技＝前脚、二段蹴り・空中連脚は1段目＝前脚・2段目＝後脚、飛び道具は投げる側の部位（壊れていると不発）。投げ・つかみ・体当たり・噛みつき・当て身は部位を使わない。CPUは壊れた部位を使う技を選ばない。
- 表示: 負傷した腕は構えが下がって震え、脚は歩くと体が沈む。肘・膝に 黄色の×（負傷）／赤い×と点滅する輪（重傷）。HUD の人型アイコン（緑→黄→橙→赤）と「負傷  腕技 +1F ・ 移動 −6%」のような一行。
- トレーニングでは無効。

## 7. 因縁（相手ごとの戦績）
VS CPU の試合結果を端末に保存する（localStorage `nf2_rec`）。観戦とトレーニングは対象外。
- 自分のキャラ×相手キャラの組ごとに、対戦数・勝敗・前回の結果・前回壊された部位を記録。
- 1ラウンド目の前に約1.8秒のカード（クリック／キー／タップでスキップ）。
  - 見出し: 初対決／雪辱戦（前回負け）／因縁の対決（前回勝ち）。「4戦目 ・ 通算 1勝 2敗」。
  - 台詞: 両者1行ずつ。キャラごとに4種（初対面／前回勝った／前回負けた／前回手足を折られた）。
  - 観客: 初対決は静か、再戦でざわめき、雪辱戦か3戦以上で総立ち（歓声と試合中のざわめきが大きくなる）。
- 前回負けたCPUは攻める頻度×1.15。
- 対戦設定画面の下に戦績の一行と「記録を消す」（2回押しで全消去）。結果画面に通算成績。

## 8. CPU
- 難易度5段階: ビギナー／ノーマル／ハード／エキスパート／ヘル（反応・ガード率・PARRY率・攻撃頻度・移動速度・コンボを続ける確率 10/35/60/80/95% が上がる）。
- キャラごとの戦闘スタイル（保ちたい間合い、詰める頻度、対空、つかみ、中距離の差し込み、ダッシュ詰め、設置）。カグラ・イヴ・ヴァンプ・ブレイズ・ゲイル・ツララは専用の判断を追加で持つ。ツララは、相手が凍えると滑走で詰め、滑り蹴り・投げ・すり抜けを使い分け、ゲージ5本で氷葬を狙う。
- コンボは当たっているときだけ続ける。必殺技はゲージが足りる中で D→S→A の順（エキスパート以上は F が先）。
- **バランスの基準**: CPU同士の総当たり（ヘル）でカグラが約70%、他は同程度。Version 64 の計測（11人、各キャラ960試合）: カグラ 71、ルリ 55、イヴ 53、タイタン 51、ブレイズ 49、ヴァンプ 49、ツララ 48、ゲイル 48、ガロウ 47、ジョーカー 43、ボルト 41。組み合わせでは ツララ対ヴァンプ 18% が低い。低い難易度ほど偏る（`02_実装状況.md` §2）。

## 11. ソースの置き場と確かめ方

### 置き場とまとめ方（Version 64 から。引っ越しの段階3 で変更）

- ゲーム本体の正本は GitHub のリポジトリ `protein-818/neon-fighter` の `src/` にある。アーティファクトと `03_最新ソースコード` は Version 64 で止め、以後は更新しない。
- 本体の script は `src/js/` の22個のファイルに分かれている。つなげる順番は `src/order.txt`、HTML の枠（`<head>`、CSS、canvas、タッチ用の部品）は `src/shell.html`。
- 公開するときは、`python3 tools/build.py` が `order.txt` の順にファイルをそのままつなげて1つの script にし、`shell.html` にはめ、公開用の変換（説明文と外付け部品の読み込み）をかけて `index.html` を作る。**公開される `index.html` は今までどおり1ファイル。** script も1つ。
- ES モジュールやバンドラーは使わない。外付け部品と確かめる道具が、最上位の名前（`mode`、`A`、`B` など）を外から読み書きしているため。
- `index.html` は直接直さない。直すのは `src/` だけ。

### 確かめ方

- 遊びの中身を変えない変更（分ける、並べ替える、整える）は、`sh tools/verify/run.sh` で確かめる。分ける前の Version 64 を基準として、次を同じ環境で並べて比べる。全部通れば終了コード 0。
  1. まとめたものが基準と1バイトも違わないか、公開側との取り決め（`check.js`）
  2. 乱数を固定した総当たり330試合（11人の全組み合わせ × 難易度 0・1・4）が1試合ずつ同じか（`seed.js`）
  3. 決まった画面66枚（PC 45・英語 12・スマホ横 9）が1画素ずつ同じか（`shots.js`・`pixcmp.js`）
  4. でたらめな入力と CPU 同士の全組み合わせで、止まらないか・NaN が出ないか（`smoke.js`）
  5. 遊んだあとの保存データ（戦績・色・設定・言語・音）が引き継がれるか（`save.js`）
  6. 読み込み時に、後ろで宣言される名前を使っていないか（`map.js`）
- 数値を触ったときは、今までどおり CPU 同士の総当たり（`node tools/verify/rr.js <本体> 4 6 4` を2回、`2 6 1`、`2 6 0`）で測り直す。
- 指紋と画像はブラウザの版で変わる。比べるときは必ず同じ環境で前後の2つを並べる。
