## 読むときの注意（公開側から。3つの文書が書かれた後に決まったこと）

資料_開発_02・03 は、プロジェクトの `03_最新ソースコード_neon-fighter.html` を相手に書かれている。リポジトリの `src/neon-fighter.html` は、それと次の2点だけ違う。`<script>` の中身は同じ。

| | プロジェクトの `03` | リポジトリの `src/neon-fighter.html` |
|---|---|---|
| 1行目の外枠（`<!doctype html><html><head>…<body>`） | ある | **ない**（`<!DOCTYPE html>` から始まる） |
| 末尾 | `</script></body></html>`（最後に改行なし） | `</script>` 改行 `</body></html>` 改行 |
| 行数 | 1,152 行 | 1,152 行（1行目がない代わりに、末尾が1行多い） |

1. **基準にするのは `src/neon-fighter.html`。** `03` ではない。段階1 の受け入れ条件が「公開中の `index.html` と1文字も違わない」で、公開中のものは外枠なし・末尾は上の形のため。資料_開発_03 の §6 の1（末尾の改行）と2（1行目の外枠）は、これで決まっている。外枠は `shell.html` に入れない。
2. **行番号が1つずれる。** 資料_開発_03 の行番号は `03` のもの。`src/neon-fighter.html` では **1を引く**（例: `start` は 280 → 279 行、script は 37〜1151 → 36〜1150 行、起動の行は 1151 → 1150 行）。
3. 分けた後の確かめは、`python3 tools/build.py --check`（公開用の `index.html` が変わらないこと）と、資料_開発_02 の道具（`src/` をまとめただけのものを、分ける前の `src/neon-fighter.html` と比べる）の両方で行う。`check.js` は公開用の `index.html` を相手にすると「script は1つ」「末尾の形」で落ちる（外付け部品の読み込みが足されているため）。相手にするのは、公開用の変換をかける前のもの。
